About these numbers

Records and points use regular-season standings. Titles and podium finishes use final playoff placements. All-time rankings default to wins, then winning percentage, then points for. Ties count as half a win for win percentage.

Franchise mode credits mapped inherited seasons to the inheriting owner. Actual-owner mode credits the person who played that season. Names come from the crosswalks, with stable Sleeper IDs used to join platform history.

Points are not adjusted for changes in scoring rules. Standings use roster totals; rivalries and highlights use weekly scores. Sleeper's 2023 totals contain two one-point differences between these sources. Unknown final placements are excluded from average finish.

Weekly regular-season records cover 2016–2025 and reconcile with standings. Verified title-bracket wins, starter-level player MVPs, and draft history cover Sleeper 2022–2025 only. ESPN postseason wins are not inferred from finish. See Data coverage for limitations.

This is an independent league archive, not affiliated with ESPN or Sleeper. Only the exported data is used; there are no live API requests.
